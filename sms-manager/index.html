Before real SMS sending

This preview does not send SMS. To activate delivery, we must connect a legitimate SMS gateway through a secure backend, add its API credentials privately on the server, and obtain approval for MOBWALLET as your sender ID. Recipients will see MOBWALLET only if the provider and destination network accept and approve it. This app is not an official MTN, bank, or mobile-money notification service.
